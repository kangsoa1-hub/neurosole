# NeuroSole 구현 및 근거 검토

기존 화면 구성과 화면 이동을 보존하고 색상·간격·서체·장식 그림을 정리했다. 피그마 파일 YagqeX9I5iHehIbQJ1Drty의 node 0-1은 2026-10-13 재접속에서도 CONNECT 403으로 접근 거부되었다. 따라서 피그마 정형외과 프레임을 확인했다고 주장하지 않는다.

실제 재활 현장 사진은 Wikimedia Commons의 Spangdahlem physical therapy rehabilitates Airmen after injury (7270858), (7270864)이다. U.S. Air Force / Staff Sgt. Chanceler Nardone, 2022-06-14, Public domain. 개별 운동의 정확한 시연 이미지가 아닌 현장 참고 사진으로 명시하며 병원 사진 업로드를 보존한다. 원본 바이트를 HTML에 포함해 오프라인에서도 표시한다.

논문 확인 내역은 verified-references.json에 DOI·PMID·초록을 보존했다. Shi 2025, Gao 2026 및 DAPA 2018은 공개 XML 원문을 내려받아 확인했다. Cicerone 2019, INCOG 2023, Cochrane 기억재활 2016 및 OCS 2015는 초록 확인으로 구분한다. 원문 확인 자료는 docs/reference-fetch에 보존한다.

30분 치료에서는 치료사가 동일 난이도 내 운동·작업 항목을 선택하고 실제 수행·도움·반응·이중과제 데이터를 기록한다. 인지 게임은 보조 훈련이며 기능 활동과 전략 훈련을 대체하지 않는다. 이중과제 시간은 운동시간의 부분집합이다. 초안 프로토콜은 관리자 임상 검토 후 배포한다.

개인화는 치료사 ID별 형식·수정 쌍·선택 이력을 축적하는 초기 단계다. 언어모델 기반 자유문장 학습 또는 검증된 임상 AI가 연결되어 있지는 않다. 월간 예측은 기준검사와 모델·계획값을 고정하는 연구용 구조이며 실제 이후 검사와 같은 환자군·검사·검사판에서 대조한다. 후보 회귀모델은 환자 단위 분할로 확인하고 관리자 승인 후 적용한다. 치료 반응/이중과제 수행값을 수집하지만 현재 회귀식은 기준점수와 계획량만 사용한다.

치매 확장은 별도 환자군으로 관리한다. DAPA RCT에서는 중등도~고강도 운동으로 인지 저하 방지 효과가 나타나지 않았으므로 치매 예방 효과나 개선 점수를 보장하지 않는다. 앱 내부 VCS는 임상 규준이 검증되지 않았으며 표준 검사와 구분한다.

환경 게시와 병원용 서버 배포는 별개다. 중앙 Node 서버와 태블릿 브라우저/PWA 구조로 구현했고 운영 서버로 파일을 이전하거나 GitHub에 별도로 저장해야 외부에서 접근할 수 있다. 기존 DB를 보존하여 서버와 HTML을 함께 업데이트해야 한다.
