# NeuroSole V52 — 데이터 파이프라인 · 데이터 사전

목표: 치료사가 매일 하는 치료를 **정량 데이터**로 남겨, "운동 + 이중과제"가 인지(MMSE 등)에 미치는 영향을 학습하는 반응형 재활치료 프로그램의 기반을 만든다.
주 인지 향상 프로토콜은 **운동 + 이중과제(exercise+dualtask)** 이며, 태블릿 인지재활 과제는 보조 기록이다(SaMD 미승인).

## 1. 매일 쌓이는 것 (치료사 입력 2탭 + 자동)
| 데이터 | 입력 방법 | 저장 키 |
|---|---|---|
| 운동 수행 기록 | P-note 각 세션 아래 "🏋 수행 기록" — 난이도 L1~5, 세트×횟수(회/분/m/초), 완수 체크 → 세션 끝 **체감강도(쉬움/적당/힘듦)·중단이유(완수/피로/통증/시간부족)** 2탭 → 저장 | `dose:<환자ID>` |
| 자동조절 | 다음 세션 처방값 = 지난 수행값. 완수+쉬움/적당 → 한 단계 ↑(횟수→세트→난이도), 힘듦/피로/통증 → 한 단계 ↓ | (계산) |
| 이중과제 정량 기록 | 🚶 이중과제 프로토콜 → 📝 수행 기록: 단일/이중과제 측정값, 인지 시도·정답, 중단 여부 → DTC·DTPI 자동 계산, P-note 줄 자동 추가 | `dtlog:<환자ID>` |
| 치료 부하 지수 | Σ 세트×횟수×난이도가중치[1,1.25,1.5,1.75,2]×단위계수[회0.1·분0.3·m0.02·초0.05] | (계산) |
| 수행 능력 지수 | 그날 완수한 항목의 최고 난이도를 영역별 평균(1~5) | (계산) |
| DTPI | 인지 정답률 × (100−DTC)/100, 0~100 | (계산) |

## 2. 매달 쌓이는 것 (결과 라벨)
- 관리자 설정 → **🗓 검사 시행일 계획**: 날짜 추가 또는 "매월 마지막 금요일(공휴일이면 전주) 12개월 자동 생성". 환자별로 다른 날짜 지정 가능(일괄 제외 옵션).
- 시행일이 되면 담당 치료사 화면 우측 검사 목록이 **노란색 + "오늘 검사"** 로 표시되고 홈 상단에 알림. 시행 후 45일까지 미시행이면 계속 표시.
- 기본 검사: MMSE · GDS · BBS · MMT · K-MBI · **VCS(시각인지 선별검사)**. MMSE/GDS는 병원 규정과 별개로 매달 태블릿 시행.

## 3. VCS — 시각인지 선별검사 (태블릿, 5~8분, 글자 의존 최소)
| 소검사 | 측정 | 점수(0~5) |
|---|---|---|
| ① 그림 기억 → ⑦ 지연 인식 | 5개 그림을 10개 중에서 고름 | 정답 − 오경보 |
| ② 기호-숫자 (60초) | 처리속도·주의 | 정답 ≥35:5 / 28:4 / 21:3 / 14:2 / 7:1 |
| ③ 선 잇기 A (1~8) | 시각 탐색 | ≤20초:5 / 30:4 / 45:3 / 60:2 / 90:1 (오류 1개당 +5초) |
| ④ 숫자-도형 교대 | 전환·실행기능 | ≤40초:5 / 60:4 / 90:3 / 120:2 / 180:1 |
| ⑤ 블록 순서 | 시공간 작업기억(Corsi) | 최대 6:5 / 5:4 / 4:3 / 3:2 / 2:1 |
| ⑥ 별 지우기 | 시각 탐색·편측 무시 | 30개 중 ≥29:5 / 26:4 / 22:3 / 17:2 / 10:1 · 무시지수 = (우−좌)/15×100 |
총점 0~30. 내부 추적용 도구(비검증)이며 표준 검사를 대체하지 않는다. 저장: `assess:<환자명>` type `VCS` (sub, raw 포함).

## 4. 예측 → 실제 → 자기 보정 (MMSE)
- 운동 수행·이중과제 기록·VCS 저장 시마다 **30일 후 MMSE 예측**을 기록(`cogpred:v2`).
  pred = 현재 MMSE + 자연회복(발병 기간대) + 운동부하×gLoad/100 + 이중과제 횟수×DTPI×gDT + VCS 변화×gVcs + 인지재활 세션×gain
- 20~75일 뒤 MMSE가 저장되면 그 기간의 **실제 투입량**으로 기대값을 다시 계산해 실제와 비교하고, 오차에 비례해 계수를 보정(클램프). 환자 화면 "인지 검사·치료 이력" 및 관리자 "인지 모니터링"에 예측 vs 실제 표·오차 추이 표시.

## 5. 학습용 데이터셋 (가명)
관리자 설정 → 🧪 AI 학습용 데이터셋 → "학습용 데이터셋 내려받기"(JSON, schema `neurosole-ds-v52`) / "매핑표 내려받기"(가명 ID ↔ 환자, 병원 내부 보관).
| 표 | 행 | 주요 컬럼 |
|---|---|---|
| patients | 환자 | pseudo_id, dx_cat(stroke_i/stroke_h/tbi/sci/other/ortho), side(L/R/B/N), age_band, onset, admit, discharged_at, sci_level, asia, gait_admit(FAC), premorbid, hand, comorb, insurance, recovery_ward |
| assessments | 검사 1회 | pseudo_id, type, date, total, 세부(MMSE 하위, VCS sub/raw …) |
| dose_sessions | 치료 세션 | session_id, date, slot, tx_type, therapist(가명), rpe, stop, load |
| dose_items | 운동 항목 | session_id, idx, text, level, sets, reps, unit, done, prev_*, load |
| dt_logs | 이중과제 시행 | dt, lv, priority, measure, single, dual, unit, dtc, cogN, cogOk, acc, dtpi, sets, stopped |
| cog_sessions | 태블릿 인지 과제 | task, domain, level, n, correct, accuracy, avg_rt_ms, level_change |
| schedule | 배정 | date, tx_type, therapist, therapist_type, slot, extra |
| pnote_items | P-note 항목 | tx_type, occurrence, idx, text |
| predictions / pred_evals | 예측·평가 | pred, base, band, feat, contrib / expected, actual, error, before, after |
이름·등록번호·전화·자유 메모는 제외. 환자 학습용 기본정보(📇)는 환자 화면 헤더 또는 관리자 처방표 이름 옆에서 입력.

## 6. 운영 권장
1. 입원 시: 📇 학습용 기본정보 입력(진단 분류·마비측·연령대·입원 시 보행·발병 전 기능).
2. 매 세션: 수행 기록 저장(2탭). 이중과제 시행 시 📝 수행 기록.
3. 매달 시행일: 우측 검사 목록 노란색 항목 시행(MMSE·GDS·BBS·MMT·K-MBI·VCS).
4. 분기마다: 데이터셋 내려받기 → 알리코어 학습 파이프라인. 매핑표는 병원 보관.
5. 연구·개발 목적 사용 전 환자 동의/IRB(가명정보 처리) 확인.

# V53 — 외부 평가 반영 사항
| 평가 지적 | 반영 |
|---|---|
| 45일 경과 시 미시행 알림 소멸 | **삭제**. 검사 완료·미시행 사유 기록(치료사 "불가" 버튼: 거부/상태불량/퇴원·외박/시행불가/기타)·관리자 취소 전까지 미완료 유지. 관리자 카드에 미완료 검사 목록(오래된 순, 14일 이상 빨강). 저장 `examskip:v1` → 데이터셋 `exam_skips` |
| 환자별 변경: 전체 vs 일부 | 개별 시행일에 할 검사를 체크로 선택(일부만 이동), "일괄 시행일 전체 제외" 체크 시 전체 이동 |
| 정규검사 vs 추적검사 구분, GDS 명칭 | 카드에 구분 표기. GDS = **Global Deterioration Scale(치매 단계)**. 데이터에 `track:'monthly'` |
| 반복 MMSE 조건 기록 | 모든 검사 기록에 검사자(by/byRole)·기기(device)·앱 버전(app). 추적용 MMSE·VCS는 협조도(상/중/하)·피로(없음/약간/심함)·대리 입력 여부 2탭 (`cond`) |
| DT3 운동-운동 과제 분리 | `dt_logs.cls` = cog-motor / motor-motor / multi. motor-motor는 acc·dtpi null, 인지 지표에서 제외 |
| 인지 정답률만으로 부족, 인지 단독 기준 | 인지과제 단독(앉아서) 시도/정답 선택 입력 → `cogDtc`(인지 DTC). 운동 DTC·인지 정답률·반응시간은 원자료로 분리 저장(DTPI는 모니터링용) |
| 문해·학력 의존 과제 구분 | `dt_logs.literacy` = numeric/verbal/color/none. VCS 핵심 5종은 문자·숫자 비의존 |
| VCS: Flanker·DCCS 추가, 숫자 과제 선택화 | **VCS v2** 핵심 5종(그림 기억·플랭커·규칙 전환(DCCS형)·블록 순서·별 지우기) 각 0~6 = 30점. 기호-숫자·숫자-도형은 선택(숫자 읽기 가능 환자). 소검사별 "불가(사유)" 건너뛰기 → 비례 환산(`prorated`). 치료사 대리 입력 플래그. 반응시간(중앙값·간섭) 원자료 저장 |
| 예측 시점 고정(미래 정보 차단) | 예측은 생성 시점 값으로 **고정**. `pred_evals.error = actual − pred`. 실투입량 재계산 값은 `expectedActualDose`(진단용)로만 저장 |
| 공변량 함께 학습 | 예측 레코드에 `cov`(진단분류·마비측·연령대·발병일수·BBS·FAC·K-MBI·GDS·VCS·기준 MMSE) 저장 → 오프라인 학습용 |
| 자동 계수 변경 통제 | 라이브 계수 **기본 고정**. 평가마다 섀도 모델만 학습. 관리자가 "검증된 섀도 모델로 교체"(평가 30건 이상 + 섀도 오차 < 라이브 오차일 때만 활성). 교체 이력 `model.history` |
| 기준모델 비교 | 자연회복만 반영한 기준모델 오차(`errorBaseline`)를 함께 기록·표시. 모델 MAE가 기준모델보다 낮아야 의미 |
| 불확실성·방향 | 예측에 ±MAE(평가 5건 이상), 개선/유지/악화 방향 표시 |
| 운동 노출량 원자료 | 세션 실제 치료 시간(분) 입력(`dose_sessions.minutes`). 세트·횟수·단위·난이도는 원자료 그대로 보존 |
| 학습/검증 환자 분리 | 앱 밖(오프라인 학습) 단계에서 pseudo_id 기준 환자 단위 분할을 권장. 데이터셋에 환자 단위 키 포함 |
