# NeuroSole 서버 설치 안내 (병원 서버 컴퓨터 1대 기준)

## 1. 준비
- Node.js 설치 확인: 시작 메뉴에서 `cmd` 실행 → `node -v` 입력 → `v20.x.x`처럼 버전이 나오면 설치된 것. 안 나오면 nodejs.org에서 **LTS → Windows Installer(.msi)** 를 받아 Next만 눌러 설치하고, 설치 후 열려 있던 명령창은 닫고 다시 실행(필요 시 재부팅).
- `install_autostart.bat`는 PATH에 없어도 `C:\Program Files\nodejs` 등 기본 설치 폴더에서 node.exe를 자동으로 찾고, 없으면 winget으로 자동 설치를 제안합니다.
- Windows/맥/리눅스 어느 PC든 됩니다. **Node.js LTS**(https://nodejs.org) 설치 — 그 외 설치할 것 없음.
- 서버 PC와 태블릿·치료실 PC가 같은 병원 내부망(Wi-Fi/유선)에 있어야 합니다.

## 2. 실행 (테스트)
- Windows: `start.bat` 더블클릭 (리눅스/맥: `./start.sh`)
- 창에 `태블릿/PC: http://192.168.x.x:8080` 처럼 주소가 표시됩니다. 서버 PC 방화벽에서 8080 포트 허용.
- 포트 변경: `set PORT=9000 && node server.js`

## 2-1. 운영 설치 (부팅 시 자동 실행)
- Windows: `install_autostart.bat`를 **마우스 오른쪽 → 관리자 권한으로 실행** (창의 안내문은 영문으로 표시됩니다 — 한글 깨짐 방지). 작업 스케줄러에 "NeuroSoleServer"가 등록되어 PC를 켜면 자동으로 서버가 뜨고, 방화벽 8080이 열립니다. 해제는 `uninstall_autostart.bat`.
- 리눅스: `sudo ./install_autostart.sh` (systemd 서비스 `neurosole`).
- 서버 PC는 절전 모드를 끄고, 공유기에서 **고정 IP(DHCP 예약)** 를 주면 태블릿 주소가 바뀌지 않습니다.

## 2-2. 태블릿에 앱으로 설치 (PWA)
- 태블릿 Chrome(안드로이드)에서 `http://서버IP:8080` 접속 → 로그인 화면의 **"📲 태블릿에 앱으로 설치"** 또는 Chrome 메뉴(⋮) → "홈 화면에 추가". 아이콘이 생기고 전체 화면으로 실행됩니다.
- iPad: Safari 공유(□↑) → "홈 화면에 추가".
- 서버의 `public/index.html`을 바꾸면 모든 태블릿이 다음 실행 때 자동으로 새 버전을 받습니다(앱을 완전히 닫았다 다시 열기).
- 오프라인: 화면은 열리고 저장은 기기에 보관되었다가 연결되면 자동 전송됩니다(상단 배지에 상태 표시). 다른 기기의 변경은 60초마다 반영됩니다.

## 3. 접속·계정
- 태블릿/PC 브라우저(Chrome·Safari)에서 `http://서버IP:8080` 접속 → 홈 화면에 추가하면 앱처럼 사용.
- 처음 실행 시 데모 계정 자동 생성: `admin/admin1234`(치료부장), `pt/pt1234`, `pt2/pt1234`(물리치료사), `at/at1234`(작업치료사), `lt/lt1234`(언어치료사). 운영 전 비밀번호를 바꾸세요(병원 설정 → 계정 관리).
- 신규 치료사는 로그인 화면 **계정 만들기** → 아이디·비밀번호·이름·역할·배치 보드 치료사 선택 → 관리자가 **병원 설정 → 계정 관리**에서 승인.
- 계정 관리에서 역할·보드 치료사 연결·비밀번호 초기화·삭제·전체 데이터 백업(JSON)이 가능합니다.

## 4. 데이터
- 모든 공유 데이터(환자·처방·배치·P-note·인지재활 결과·설정)는 `data/db.json`에 저장되고, 6시간마다 `data/backup/db-날짜.json`으로 백업됩니다.
- 다른 PC로 옮길 때는 `server` 폴더 전체를 복사하면 됩니다.
- 브라우저만 열어 쓰는 파일 방식(`neurosole_app.html` 더블클릭)은 그 브라우저에만 저장되므로, 여러 기기에서 같이 쓰려면 반드시 서버 방식으로 접속하세요.

## 5. 업데이트
- 새 버전의 `index.html`을 `public/` 폴더에 덮어쓰고 서버를 재시작(start.bat 다시 실행)하면 됩니다. 데이터는 유지됩니다.

## 6. 데이터 연동(알리코어 등 외부 시스템)
- 모든 데이터는 키-값(JSON)이며 서버가 키별 수정 시각·수정자·버전(`meta`)과 주요 데이터 감사 로그(`audit`)를 기록합니다.
- API (Bearer 토큰, `/api/login`으로 발급):
  - `GET /api/kv/all` 전체 · `GET /api/kv/<key>` 단일 · `GET /api/kv/since?ts=ISO` 변경분 · `POST /api/kv {items:[{key,val}]}` 저장
  - `GET /api/export` (관리자) 전체 덤프(users·kv·meta·audit) — 백업·이관·연동용
- 주요 키: `patientInfo:<환자>`(검사 점수·주간 프로토콜), `assess:<이름>`(검사 이력), `cogsess:<환자>`(인지재활 세션·문항), `cogsheet:<환자>`(결과지), `deptsched:patients`(처방), `deptsched:board:<날짜>`(배치), `exec:<환자>`·`extraTx:<환자>`(치료 기록·P-note), `pnfix:<환자>:tx:<타입>`(P-note 항목), `pnlearn:v1`(학습), `cogcfg:v1`·`pnbank:custom:v1`·`deptsched:config`(설정). 자세한 구조는 `docs/01_데이터모델.md`.

## 7. 업데이트 (지우고 다시 깔 필요 없음)
- 관리자 로그인 → **병원 설정 → 프로그램 업데이트** → 새 `neurosole_app.html` 선택 → 업로드·적용. 서버가 즉시 교체하고 이전 버전을 `public/backup/`에 보관(되돌리기 가능).
- 접속 중인 태블릿·PC는 3분 안에 상단에 "새 버전 — 지금 업데이트" 배너가 뜨고, 누르면 새로고침으로 적용됩니다(앱을 다시 열어도 적용). 저장 중이던 내용은 먼저 서버로 전송됩니다.
- 수동 교체도 가능: `public/index.html` 덮어쓰기(서버 재시작 불필요).

## 8. 관리자 PC가 서버가 아닐 때
- 서버는 별도 PC 한 대에 두고, 관리자·치료사 모두 브라우저로 `http://서버IP:8080`에 접속하면 됩니다(권장).
- 파일로 받은 `neurosole_app.html`을 그냥 열어도 로그인 화면의 **서버 주소** 칸에 `http://서버IP:8080`을 넣고 "연결"하면 같은 서버 데이터로 동작합니다.

## 9. 데이터가 저장되는 곳 (AI 학습 데이터 수집)
- **서버 모드(권장)**: 모든 데이터는 서버 PC의 `server/data/db.json` 한 파일에 저장됩니다(6시간마다 `data/backup/`에 사본). 태블릿·PC에는 남지 않습니다.
- **파일 모드(neurosole_app.html을 그냥 연 경우)**: 그 브라우저의 로컬 저장소(localStorage)에만 남아 다른 기기와 합쳐지지 않으므로, 데이터 수집 목적이면 반드시 서버 모드로 쓰세요.
- 저장 단위(키): `patientInfo:<환자>` 검사 점수(MMSE·MMT·BBS·FAC·NeuroCog·GDS·K-MBI…)와 주간 프로토콜 / `assess:<이름>` 검사 이력(날짜별) / `cogsess:<환자>` 인지재활 세션(과제·단계·정답률·반응시간·오류·문항별 기록) / `cogsheet:<환자>` 인지치료 결과지 / `pnfix:<환자>:tx:<치료>` P-note 항목 / `exec:<환자>` 치료 수행 기록·점수·자유 편집 노트 / `extraTx:<환자>` 연하·VitalStim 등 / `deptsched:board:<날짜>` 그날 배치 / `pnlearn:v1` 치료사 선택 학습 데이터
- **AI 학습용 내보내기**: 관리자 → 병원 설정 → 계정 관리 카드의 **"🧠 AI 학습용 데이터셋 내보내기"** → 정규화된 표(patients, assessments, cog_sessions, cog_trials, cog_sheets, pnotes, exec_records, schedule)를 JSON과 JSONL 텍스트로 내려받습니다. API: `GET /api/dataset` (관리자 토큰).
- 개인정보: 환자 이름·등록번호가 포함되므로 외부 반출 시 `sys_id`만 남기고 이름을 제거(가명화)하세요. 서버 PC는 병원 내부망에만 두고 백업 폴더를 주기적으로 안전한 곳에 복사하세요.

## 10. 태블릿(Wi-Fi)에서 접속이 안 될 때
서버 PC에서 `check_network.bat` 를 실행하면 서버 IP·8080 포트·방화벽 규칙·네트워크 프로필을 한 번에 확인합니다.
- 태블릿 Wi-Fi 설정의 IP가 서버와 같은 대역(예: 192.168.0.x)이어야 합니다. 다르면(220.x / 172.30.x / 192.168.1.x 등) Wi-Fi 공유기가 별도 네트워크입니다 → Wi-Fi 공유기를 서버가 연결된 공유기 아래에(LAN 포트, AP 모드/브리지) 연결하거나, 서버 PC를 그 Wi-Fi에 연결하세요.
- 같은 대역인데도 안 되면 공유기의 "AP 격리(무선 단말 간 통신 차단)" 또는 게스트 네트워크를 해제하세요.
- 서버 PC 방화벽 규칙 `NeuroSole 8080`이 없으면 `install_autostart.bat`를 관리자로 다시 실행하세요.

## 13. V54 — 운영 시작(예시 데이터 삭제)
- 새 서버는 **admin/admin1234 계정 하나만** 만들어집니다(예시 계정 pt/pt2/at/lt는 `--demo` 옵션으로 실행할 때만). 기존 서버에 이미 있는 예시 계정은 설정 → 계정 관리에서 삭제하세요.
- 처음 접속하면 예시 환자 32명·예시 치료사가 들어 있습니다(화면 익히기용). 실제 운영 전 **설정 → 🏥 데이터 모드 → "예시 데이터 삭제하고 운영 시작"** 을 누르면 환자·치료사·배치·검사·학습 데이터가 모두 지워지고(백업 JSON 자동 저장), 이후 예시 데이터는 다시 생기지 않습니다.
- 운영 모드에서 환자는 처방표 → ➕ 입원 환자 등록으로 한 명씩 등록하고, 치료사는 각자 가입(명단 비워 둠) → 관리자 승인 시 배치 보드 명단에 자동 등록됩니다.
- 관리자가 기본 비밀번호(admin1234)로 로그인하면 경고가 뜹니다. 계정 관리 → 비번 초기화로 바꾸세요.
- 로그아웃 시 서버 저장 큐를 먼저 비워 저장 유실을 막습니다.

## 14. V55 — 휴무일

## 15. 업데이트 방법 요약
- 화면·기능 변경(거의 모든 업데이트): 관리자 설정 → 🔄 프로그램 업데이트에 neurosole_app.html 업로드 → 끝.
